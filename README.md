# WellMe Functional v1

This version turns the visual prototype into a working browser prototype.

Included:
- Health report upload (PDF/image) with local browser storage
- Basic PDF text extraction for common lab names
- Add meals and estimated calories/protein
- Log workouts
- Add/toggle supplements
- Pet selection saved locally
- Data persists in localStorage

Important:
- This is still a prototype; no health data is sent to a backend.
- PDF extraction is basic and may miss tables/scanned PDFs.
- AI analysis, secure accounts/database, OCR, Apple Health, and friend/couple features come next.
